# Pouls Crypto

Application web pour lire l'état d'une crypto sur téléphone : régime sur 6 unités de temps, levier (open interest, funding), degré de peur, signaux de squeeze ou de capitulation, niveaux FVG et plan de trade.

Données : Binance (contrats perpétuels USDⓈ-M) et l'indice Fear & Greed de CoinMarketCap, lus par un relais Supabase (fonction « pouls », données publiques de marché uniquement, sans clé). En secours, l'application lit directement Bybit et alternative.me.

Adresse : https://sayoc44.github.io/pouls/
